# Instalador de Alaska Caja

`AlaskaCaja-Instalador.zip` contiene la aplicación de Windows, el instalador y el
runtime Python oficial embebido. Extrae el ZIP y ejecuta `Instalar.cmd`.

No contiene claves ni el registro de órdenes de ningún equipo. Los datos locales
se conservan en `%LOCALAPPDATA%\AlaskerpPrint\data`.
